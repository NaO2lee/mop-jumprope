## 3. 녹화 저장소 전략 (KST 00:09)

**문제**: 녹화 파일이 현재 클라이언트에 다운로드만 됨. 탭 닫으면 유실. Firebase Storage 는 비용·용량 한계.

**쟁점**:
- 클라우드(Firebase Storage / S3) — 안정성·접근성 ↑ but 비용 ↑
- NAS — 비용 ↓ but 네트워크 의존, 로컬 종속
- 하이브리드 — 가장 균형 잡힘

**어떻게 파악**: 사용자가 비용을 우려하며 NAS 활용 가능성 질문.

**돌파구 (제안)**:
```
[카메라 폰] → [WebDAV/HTTP 업로드] → [NAS (Synology/QNAP)]
                                       ↓
                                  [Cloudflare Tunnel
                                   또는 MinIO S3 API]
                                       ↓
                              관전·심판 후 영상 검토
```

- NAS 도 **Cloudflare Tunnel** 로 외부 접근 가능 (이미 madelee.weplaykorea.com 으로 검증됨)
- **MinIO** 를 NAS 에 설치하면 S3 API 호환 — 코드는 S3 라이브러리 그대로 사용
- 비용 비교 (4TB · 1년):
  - Firebase Storage: 약 80만원/년
  - AWS S3: 약 55만원/년
  - NAS (Synology DS224+ + WD Red 4TB×2 RAID-1): 일회성 약 140만원, 그 이후 전기료만

**진행 결과**:
- 사용자 의견 수렴 후 (NAS 모델 선정 등) 진행 예정
- 우선 코드 측에서는 **추상화 인터페이스**(`uploadRecording(blob, key)`) 만들어두고 백엔드(Firebase Storage / S3 / NAS WebDAV) 는 환경변수로 스위치 가능하게 설계
