## judge.html

### 코트 입력 → 드롭다운 (오타·불일치 차단)
- 자유 텍스트 input → `<select>` 로 변경
- `loadCourtOptions(room)`: 해당 룸의 heats 1회 읽어 실제 존재하는 코트 키만 자동 목록화
- URL/localStorage 코트 값은 드롭다운 로드 후 자동 선택 (`_desiredCourt` 변수)
- `startApp` 가 드롭다운 미로드 케이스에서 `_desiredCourt` 로 폴백

### 선수 QR 스캔 (세션 중)
- html5-qrcode CDN 추가 (`v2.3.8`)
- 메인 화면 상단에 `📷 선수 QR 스캔` 버튼 + 스캐너 모달 (`#scan-modal`)
- `openScan()` / `closeScan()` / `onScanSuccess(text)` 함수
- 스캐너가 인식한 URL → `runAthleteLookup({bib, event})` 호출
- pointerType 검증, in-flight 잠금, 디바운스 적용 (이중 인식 방지)

### `runAthleteLookup` 분기 (진위 확인 vs 점프)
- 현재 코트의 표시 선수와 bib + event 일치 → **`athleteStatus='arrived'`** 확정 (도착 진위 확인 모드)
- 다른 히트/코트 선수 → 해당 히트로 자동 점프 (플로팅 심판 흐름)
- `verifiedBy:'qr'` + `verifiedAt` Firebase 기록

### QR 진위 확인 정책 (준비 버튼 게이트)
- 이전: `toggleReady` 가 첫 누름 시 `athleteStatus='arrived'` 자동 설정
- 변경: `toggleReady` 는 `athleteStatus==='arrived'` 일 때만 동작; `pending` 이면 토스트 "📷 선수 QR 스캔으로 진위 확인 후 준비 가능"
- `updateReadyBtn`: pending 상태에선 라벨 "📷 QR 스캔 필요" + 톤 다운
- `resetJudgeState`: 히트 변경 시 `verifiedBy`/`verifiedAt` 초기화 (새 선수도 다시 QR 필수)

### 수동 도착 확인 (폴백)
- QR 스캔 버튼 옆에 `✋ 수동확인` 추가 (배번카드 분실·카메라 고장·테스트용)
- `manualVerify()`: confirm 다이얼로그 → `athleteStatus='arrived'` + `verifiedBy:'manual'`

### 시작 시퀀스 READY → SET → GO! 카운트다운
- 전체화면 오버레이 (`#countdown-overlay`) + 색상별 애니메이션 (READY 노랑 / SET 빨강 / GO 초록)
- 비프음 타이밍 동기 (0s / 0.35s / 0.7s)
- ★ **카운트 게이트는 GO 시점에만 오픈** → 그 전 탭 무효 (유효타 보장)
- 종료 신호 시 게이트 차단 + 오버레이 hide

### +1 버튼 이중 카운트 근본 해결
- `onpointerdown` → `onclick` 으로 통일 (`-1` / `+10` 버튼과 동일 패턴)
- pointerdown 의 호환용 합성 mouse 이벤트로 인한 이중 발화 구조적 차단
- 60ms 디바운스 안전장치 유지

### `?dev=1` 테스트 모드

## operator.html

### 코트 LED 색상 의미 재정의
- 심판 링크 연결 → **초록 LED** (이전: 흐린 회색)
- 준비 완료 → **밝은 초록 + 점멸**
- 박스 배경: 연결 + 선수 있으면 옅은 초록 (`rgba(0,255,136,.045)`)

### 시작 버튼 게이트 (`canStart`)
- 선수 배정된 모든 코트에서 `ready===true` 또는 `athleteStatus==='no_show'` 이어야 활성
- 미충족 시 `▶ HEAT 시작` 비활성 + sub 에 대기 중인 코트 명시: "⚠ N개 코트 대기 — A·B·..."
- 라벨 통일: "▶ HEAT N 시작" (이전 "음원 재생" / "시작 신호음" → heat 시작이 핵심 액션임을 강제)

### 시작 시퀀스 분리 (헤더 → 3.5s → 신호)
- Phase 1: TTS "히트 N번. [종목명]." (음성만, 비프 없음)
- Phase 2 (3500ms 후): `_startingSeqRef` 가드 해제 → 음원 모드면 MP3, 합성 모드면 `SIG.start()` + `fbSig('start')`
- `doPlayTrack` cleanup: 중복 `ment('start')` 제거, `audio.onended` 에 `fbSig('end')` 추가 (단, 합성 `SIG.end()` 는 MP3 내장 종료음과 중복이라 제거)
- 종료 안내 TTS 는 유지 ("종료음 → 종료 안내 멘트" 사용자 흐름)

### 선수 부재 자동 안내 (transition trigger)
- `prevAthleteStatusRef` + `lastNoShowHeatRef` 로 상태 전환 추적
- 심판이 no-show 토글 순간만 1회 발화 (재발화 방지, 초기 마운트 제외)
- 메시지: "코트 A. [소속] 소속 [이름] 선수, 부재 확인됩니다."

### 부재 재안내 버튼 (수동 트리거)
- CourtBox 의 ❌ 부재 표시가 **클릭 가능한 버튼** ("❌ 부재 · 📢 재안내")
- `doRecallAbsent(cid)`: "다시 한 번 말씀드립니다. [소속] [이름] 선수, 담당 코트 X, 입장해 주시길 바랍니다."
- 현재 `lang` 설정 (한/영/한+영) 그대로 적용

### 음성 기본값 변경
- 톤 프리셋 기본 `default` → `sports` (🏟 스포츠 캐스터)
- 한국어 자동선택 1순위: `Google 한국의`
- 영어 자동선택 1순위: `Google US English`

### 진행 상태 리셋 (`doResetRun`)
